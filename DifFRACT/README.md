# DifFRACT project page

The project page of *DifFRACT: Diffusion Feature Reconstruction and Attribution for Circuit Tracing*
(NeurIPS 2026), live at **https://artalmaz31.github.io/DifFRACT/**.

- Paper: https://arxiv.org/abs/2606.15796
- Code: https://github.com/Artalmaz31/DifFRACT
- Transcoders: https://huggingface.co/Artalmaz31/DifFRACT

## Viewing it locally

```bash
python -m http.server 8000
```

Run it in this folder, then open http://localhost:8000.
