The transcoder

A transcoder modulates the MLP input xx with the timestep (FiLM4, whose scale and shift come from a small network on a sinusoidal code of tt), encodes it sparsely and decodes linearly:

xmod=x⊙(1+scaletc(t))+shifttc(t),z(x,t)=ReLU(Wenc xmod+benc),TCℓs(x,t)=Wdec z(x,t)+bdecx_{\m{mod}} = x \odot \bigl(1 + \m{scale}^{\m{tc}}(t)\bigr) + \m{shift}^{\m{tc}}(t), \qquad z(x, t) = \m{ReLU}\bigl(W_{\m{enc}}\, x_{\m{mod}} + b_{\m{enc}}\bigr), \qquad TC^s_\ell(x, t) = W_{\m{dec}}\, z(x, t) + b_{\m{dec}}

Feature ii has an encoder vector fenc(ℓ,s,i)f^{(\ell, s, i)}_{\m{enc}}, a row of WencW_{\m{enc}}, and a decoder vector fdec(ℓ,s,i)f^{(\ell, s, i)}_{\m{dec}}, a unit-norm column of WdecW_{\m{dec}}. The loss divides the squared error by the variance of the MLP output, so that one sparsity coefficient per stream means the same for all 32 transcoders:

ℒℓs=𝔼x,t ∥MLPℓs(x)−TCℓs(x,t)∥22∑jVarx,t(MLPℓs(x)j)+ε+λs 𝔼x,t ∥z(x,t)∥1\mathcal{L}^s_\ell = \frac{\mathbb{E}_{x, t}\,\|\m{MLP}^s_\ell(x) - TC^s_\ell(x, t)\|_2^2}{\sum_{j} \m{Var}_{x, t}\bigl(\m{MLP}^s_\ell(x)_j\bigr) + \E} + \lambda^s\, \mathbb{E}_{x, t}\,\|z(x, t)\|_1

The local replacement model

One forward pass on the traced prompt at step tt caches the LayerNorm denominators νcached\nu_{\m{cached}}, the attention probabilities PℓP^\ell and the reconstruction errors. The model is then run with three substitutions in blocks 0 to 15:

FrozenNormℓ,s(x)=(x−xˉ)⊙νcachedℓ,s,FrozenAttnℓ(ximg,xtxt)s=WO(ℓ,s)((Pℓ Vcatℓ(ximg,xtxt))s)+εattnℓ,s\m{FrozenNorm}_{\ell, s}(x) = (x - \bar{x}) \odot \nu^{\ell, s}_{\m{cached}}, \qquad \m{FrozenAttn}_\ell(x_{\m{img}}, x_{\m{txt}})_s = W_O^{(\ell, s)}\bigl((P^\ell\, V^\ell_{\m{cat}}(x_{\m{img}}, x_{\m{txt}}))_s\bigr) + \E^{\ell, s}_{\m{attn}}
MLPℓ,sLRM(x)=TCℓs(x,t)+εmlpℓ,s,εmlpℓ,s=MLPℓs(xℓ,s)−TCℓs(xℓ,s,t)\m{MLP}^{\m{LRM}}_{\ell, s}(x) = TC^s_\ell(x, t) + \E^{\ell, s}_{\m{mlp}}, \qquad \E^{\ell, s}_{\m{mlp}} = \m{MLP}^s_\ell(x^{\ell, s}) - TC^s_\ell(x^{\ell, s}, t)

On the cached input the output is unchanged, and with the active features held fixed every component is affine.

The weight of an edge

The preactivation of the target f∗f^* at layer ℓ∗\ell^*, stream s∗s^*, position p∗p^* is its encoder vector applied to the modulated input of its MLP. Both modulations, the block's AdaLN and the transcoder's FiLM, are constants at a fixed tt, so h∗h^* is affine in the residual stream and therefore in every upstream source. One backward pass gives its gradient with respect to the residual stream of every layer, stream and position:

gℓ,s(p)=∂h∗∂rpℓ,sg^{\ell, s}(p) = \frac{\partial h^*}{\partial r^{\ell, s}_p}

Gradients do not flow through MLP outputs, so gg depends only on cached quantities. A source is read off at the point where it enters the residual stream. A feature writes its decoder vector through the gate of its block, an MLP error enters through the same gate, and an input embedding enters block 0:

A(ℓ,s,p)err→f∗=(εmlpℓ,s(p)⊙gatemlpℓ,s)⊤gℓ+1,s(p),A(s,p)in→f∗=r0s(p)⊤ g0,s(p)A_{(\ell, s, p)_{\m{err}} \to f^*} = {\bigl(\E^{\ell, s}_{\m{mlp}}(p) \odot \m{gate}^{\ell, s}_{\m{mlp}}\bigr)}^{\top} g^{\ell + 1, s}(p), \qquad A_{(s, p)_{\m{in}} \to f^*} = r^s_0(p)^{\top}\, g^{0, s}(p)

The frozen attention mixes the values of both streams, so the gradient of one stream flows into the residuals of both. A text feature's edge into an image target needs no special case: it is the same formula, and it is how the graphs show text becoming image.

What the edges sum to

Before any edge is dropped the contributions add up exactly to the target's preactivation minus a constant beff∗b^*_{\m{eff}}: the target's encoder bias, the modulation shifts seen through its encoder, and, weighted by gg (by ∂h∗/∂xmid\partial h^* / \partial x_{\m{mid}} for the target block's own attention), the parts of earlier sublayers that do not depend on the input (the frozen attention at zero input, the attention error, the decoder biases).

From edges to a pruned graph

With the absolute edge weights normalized per destination, AnormA^{\m{norm}}, the influence of a vertex sums the strengths of all its paths to the target:

B=(I−Anorm)−1−I,infl(v)=Bv,f∗B = (I - A^{\m{norm}})^{-1} - I, \qquad \m{infl}(v) = B_{v, f^*}

Edges below τ=10−3\tau = 10^{-3} are not recorded. Sources are expanded in turn, 50 at a time, ranked by their edges into the expanded vertices weighted by how far those reach the target, until 1,000 have their own incoming edges. The features never expanded become truncation-error vertices. All positions of a feature are then summed into one vertex, which keeps the identity above exactly. Pruning keeps, within each stream, the feature and input vertices that carry 80% of the influence on the target (error vertices are never pruned), then the edges that carry 98% of the remaining influence. Two steps lose part of the sum: the threshold τ\tau, in edge extraction and in compaction, and pruning. Both losses are reported under Evidence.
